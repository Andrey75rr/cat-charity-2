## О проекте

**QRKot (Quick Kot)** позволяет создавать целевые благотворительные проекты («Помощь приюту», «Лечение котиков» и т. д.) и принимать пожертвования, которые автоматически распределяются между открытыми проектами.

### Основной функционал

- Управление целевыми проектами: создание, редактирование, удаление
- Приём пожертвований с возможностью оставить комментарий
- Автоматическое инвестирование: средства распределяются между открытыми проектами в порядке очереди
- Аутентификация и авторизация пользователей через FastAPI Users (JWT)
- Разграничение прав: анонимный пользователь, зарегистрированный, суперпользователь

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd cat-charity-2
```

### 2. Создание и активация виртуального окружения

```bash
python -m venv venv
```

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
SECRET=your_secret_key_here
AUTH_SECRET=your_auth_secret_here
AUTH_TOKEN_LIFETIME_SECONDS=3600
```

### 5. Применение миграций

```bash
alembic upgrade head
```

### 6. Создание суперпользователя

```bash
python create_superuser.py
```

### 7. Запуск приложения

```bash
uvicorn app.main:app --reload
```

Сервер будет доступен по адресу: **http://127.0.0.1:8000**

Документация API:
- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## API эндпоинты

### Аутентификация — `/auth`

| Метод | Эндпоинт | Описание | Доступ |
|---|---|---|---|
| `POST` | `/auth/register` | Регистрация нового пользователя | Все |
| `POST` | `/auth/jwt/login` | Получение JWT-токена | Все |
| `POST` | `/auth/jwt/logout` | Выход (удаление токена) | Авторизованные |

### Пользователи — `/users`

| Метод | Эндпоинт | Описание | Доступ |
|---|---|---|---|
| `GET` | `/users/me` | Получить свой профиль | Авторизованные |
| `PATCH` | `/users/me` | Редактировать свой профиль | Авторизованные |
| `GET` | `/users/{id}` | Получить профиль пользователя | Суперпользователь |
| `PATCH` | `/users/{id}` | Редактировать пользователя | Суперпользователь |

> Удаление пользователей отключено.

### Проекты — `/charity_project`

| Метод | Эндпоинт | Описание | Доступ |
|---|---|---|---|
| `GET` | `/charity_project/` | Список всех проектов | Все |
| `POST` | `/charity_project/` | Создать новый проект | Суперпользователь |
| `PATCH` | `/charity_project/{project_id}` | Редактировать проект | Суперпользователь |
| `DELETE` | `/charity_project/{project_id}` | Удалить проект | Суперпользователь |

### Пожертвования — `/donation`

| Метод | Эндпоинт | Описание | Доступ |
|---|---|---|---|
| `GET` | `/donation/` | Список всех пожертвований (полная информация) | Суперпользователь |
| `POST` | `/donation/` | Создать пожертвование | Авторизованные |
| `GET` | `/donation/my` | Свои пожертвования | Авторизованные |

## Права доступа

### Анонимный пользователь
- Просматривать список всех проектов
- Регистрироваться

### Зарегистрированный пользователь
- Всё, что доступно анонимному
- Создавать пожертвования
- Просматривать свои пожертвования (только поля: `id`, `comment`, `full_amount`, `create_date`)

### Суперпользователь
- Всё, что доступно зарегистрированному
- Создавать, редактировать, удалять проекты
- Просматривать все пожертвования со всеми полями

### Запрещено всем
- Удалять пользователей
- Редактировать или удалять пожертвования
- Редактировать или удалять закрытые проекты
- Удалять проекты, в которые инвестированы средства
- Изменять даты создания и закрытия проектов

## Правила валидации

### CharityProject

| Поле | Ограничения |
|---|---|
| `name` | от 1 до 100 символов, уникальное, обязательное |
| `description` | непустая строка, обязательная |
| `full_amount` | целое число > 0, обязательное |

### Donation

| Поле | Ограничения |
|---|---|
| `full_amount` | целое число > 0, обязательное |
| `comment` | опционально, строка (по умолчанию — пустая строка) |

---

## Логика инвестирования

1. При создании **нового проекта** нераспределённые пожертвования автоматически направляются в него.
2. При создании **нового пожертвования** средства распределяются между открытыми проектами в порядке их создания.
3. Проект считается **закрытым**, когда сумма пожертвований достигает целевой суммы (`invested_amount >= full_amount`).
4. Пожертвование считается **полностью распределённым**, когда все средства переведены в проекты.
